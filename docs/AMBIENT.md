# MAKU（幕間機）仕様

プロジェクト名は MAKU。もとは Felucca（Leo Kuroshita、GPL-3.0-only）。画面・起動画面・コンソール・USB の INFO の表示名は MAKU に替えた。USB のデバイス名、ローダーの識別子、パッケージの識別子、`FELUCCA_*` のビルドオプション、ファイル名は、互換と履歴のためそのまま。

DJイベントなどで、ささっとつないでとりあえずの音を出す機械。
電源を入れた瞬間から、その場限りのアンビエンスが**常に鳴っている**。パラメータに触れるほど盛り上がっていく。

MAKU（docs/MAKU.md）を本体にし、それ以外の機能は大胆に捨てる。

## 原則

- 設定してから鳴らすのではない。電源を入れたら、もう鳴っている。
- 保存はしない。起動するたびに、**ランダムなパラメータ**から始まる。
- 1つのパラメータに細かく触れられることに価値はない。回せば良い方向に動くことに価値がある。
- 画面遷移もメニューもない。ボタン1つが動詞1つで、押せばすぐに音で返ってくる。

## 4つの役（トラック）

| # | 役 | 中身（MAKU） |
|---|---|---|
| 1 | 脈 | キック（DRUM） |
| 2 | 床 | ドローン（PHYS） |
| 3 | 霞 | シマー（GRAIN） |
| 4 | 声 | アルペジオのフレーズ（PHYS） |

起動時には、音源、音色、根音、スケール、テンポ（例：70〜90 BPM）、各トラックの3つのパラメータをランダムに決める。素材の幅は、残す音源の範囲（PHYS・GRAIN・DRUM、ANALOG は候補）で持たせる。

## 操作子

- **KNOB 1〜4**：トラック1〜4の**音量**。この役割は常に変わらない。
  - 少しでも回すと、そのトラックに**フォーカス**が移り、画面がそのトラックの内側になる。
- **SELECT / PRESETS / ALGORITHM**：フォーカス中のトラックの3つのパラメータ。どれも、回せば盛り上がる方向に動く。
- **MASTER**：全体の音量（ハードウェア）。
- **鍵盤**：押した音がそのまま鳴る。音はフォーカス中のトラックの声になる。スケールで補正しない。アボイドノートもスパイスとして鳴らす。

## ボタン（1つに動詞1つ）

| ボタン | 動詞 | 振る舞い |
|---|---|---|
| HOME | 振り直し | 長押しで、新しいランダムな世界に移る |
| SEQ | テンポ | 押している間、SELECT が BPM（1刻みで1。MIDIクロックが来ていれば追従する）、PRESETS が SWING（アルペジオの揺れに足す）、ALGORITHM が DUCK（キックが他を沈める深さ。64 が従来）。トラックごとのゲインとソロはない（黒鍵のミュート、C4 の全解除、F4 のタップテンポは残る） |
| ARP | 根音・スケール | 押して離す（タップ）たびに、スケールが MAJ → MIN → LYD → DOR → MIX → PHRY → PEN → MPEN → MAJ …とメジャー系とマイナー系が交互に巡る。押している間は、弾いた鍵の音に根音が移り、SELECT が ROOT（半音）、PRESETS が SCALE（上の順）、ALGORITHM が REG（ドローンの音域 LOW / MID / HIGH）になる |
| OCT− / OCT+ | 転調（五度圏） | 押すたびに根音が五度下（♭が1つ増える）／五度上（♯が1つ増える）へ移る。移調ではなく調号の付け外し：すでに弾かれた音（溶け込んでいる音、進行中のアルペジオのフレーズ）は高さを保ったまま、調号が変える1音だけが半音動く（C→G で F→F♯）。鳴っている和音は鳴り止むまでそのまま、次の和音から新しい根音で始まる。鍵盤のオクターブ操作はない |
| PLAY | 漂う（DRIFT）のスイッチ | タップで DRIFT のオン／オフ。オンの間は PLAY が緑に点灯する。押している間は RATE / RANGE / REACH が SELECT / PRESETS / ALGORITHM に出て、つまみを回したときは、離してもオン／オフは変わらない。オンの間、値が少しずつ（ランダムウォークで）動き、止めても離した場所に残る。動くのは、4パート×3つのマクロ。REACH が 43 以上なら空間（キック以外の送りと、マスターの高域）も、86 以上ならテンポ・SWING・DUCK も（テンポは内部クロックのときだけ）。オンにした瞬間の値から RANGE の半分より遠くへは行かない。オンの間に手で動かした値は、その値が新しい基準になる。新しい世界ではオフに戻る |
| SAVE / REC | （機能なし） | 弾いた音は、REC を押さなくても常に場のフレーズへ溶け込む（下記） |

上段の6つ（FX SCL ENV LFO EDIT GLO）は**押している間だけ効く変化の動詞**。それぞれが別の軸を持ち、同じ資源を2つの動詞が触らない。

| ボタン | 動詞 | 軸 | 振る舞い |
|---|---|---|---|
| FX | 潜る（SINK） | 奥行き：奥へ沈む | キックが消え、キック以外のリバーブ送り・ディレイ送り・リバースが約1.5秒で深まる。同時に、リバーブの尾のフィードバックが 0.99 近くまで上がり、響きが吸い込まれていく。離すと約3秒かけて、キックがフェードインし、潜りも戻る。SELECT が SINK（フィードバックの深さ）、PRESETS が WASH（送りの深さ）、ALGORITHM が HUSH（キックをどこまで消すか）。既定は 100 / 127 / 127 |
| SCL | 降り注ぐ（CASCADE） | 音域と音数：上へ広がる | アルペジオが全ステップで鳴り（息継ぎの5ステップも）、1オクターブ上・2オクターブ上が重なり、スケールの3度上が重なる。DENSE（毎ステップの発音確率）/ SPAN（32 以上で +1 oct、80 以上で +2 oct）/ HARM（3度上が重なる確率） |
| ENV | 膨らむ（SWELL） | 時間：長く伸びる | 床・霞・声の、これから鳴る音のアタックとリリースが伸びる。持続する声部は次の和音を打たずに今の和音を鳴らし続け、打つ声部は同じ和音を繰り返す。ATTACK / RELEASE / STAY（和音が続く確率） |
| LFO | 揺れる（WOBBLE） | 動き：周期的に揺れる | 床・霞・声のフィルターLFOが速く深くなり、コーラスの送りが上がり、ピッチが揺れる。RATE / DEPTH（フィルターLFOの深さとコーラスの送り）/ PITCH（ピッチLFOの深さ） |
| EDIT | 持ち上げる（LIFT） | 音色：前へ、明るく、硬く | 4トラックすべての TONE マクロ（PRESETS）が足し分だけ上がり、キック以外の歪みが増し、マスターのハイパスが上がる（高域が残り低域が細る）。TONE / EDGE（歪み）/ THIN（ハイパス） |
| GLO | 崩す（SCRAMBLE） | 秩序：拍とフレーズが崩れる | アルペジオが表のあちこちへ跳び、再抽選が増え、キックのゴーストが散り、アルペジオの揺れが増す。ARP / KICK / SWING |

対になる組：SINK（奥へ）と LIFT（前へ）、SWELL（ゆっくり・長く）と SCRAMBLE（細かく・乱れる）、CASCADE（音が増える）と WOBBLE（音は増えず揺れる）。KEEP は廃止した。

### キックにフォーカスしているとき

キックは音の高さより、鳴る位置が大事。キックのトラックにフォーカスしている間だけ、鍵盤は16ステップのシーケンサーになる。

- **白鍵16個**：ステップ1〜16。押すとそのステップがオン／オフ。ACC（黒鍵9）を押しながらだと強拍。LED は鳴るステップが点灯し、再生位置が反転して流れる。
- **手で打った拍は、常に鳴る。** 密度（SELECT）は、その上に足す「ゴースト」の確率になる。ゴーストは保存しない。
- **黒鍵1〜8**：サーッというノイズやチリッとした音の装飾パッド。押すと鳴るだけで、パターンは変わらない（暗い方から：ライド2のシャリ、ロングギロのこすれ、ペダルハット、カバサ、タンバリン、マラカス、オープンハット、スプラッシュ。クラップやスネアのような胴のある音は入れない）。黒鍵9は ACC、黒鍵10・11は無機能。
- **密度（SELECT）がキックの並びを決める。** 4〜39でステップ1が気配から確かに、40〜67でステップ9が、68〜95でステップ5・13が加わり、**96以上で4つ打ち（1・5・9・13）が確率100%**になる。96を超えると、キックには触らずに装飾音（同じ DRUM トラックのハット）が確率で足されていく：裏拍（3・7・11・15）のオープンハットは96から立ち上がって127で確実に、そのほかの16分（偶数番の弱拍）のクローズハットは104から最大60%。ボイスが足りなくなるので、96を超えると床のコードは2声（根音と5度）になる。

### ボタンのパラメータ（動詞の共通の決まり）

HOME 以外のボタン（動詞）は、押している間に、画面の3つの区画がその動詞の3つのパラメータ（名前・値・ゲージ）に入れ替わり、SELECT / PRESETS / ALGORITHM で動かせる。値は次の HOME 長押し（新しい世界）まで残る。上段の6つ、SEQ（BPM / SWING / DUCK）、ARP（ROOT / SCALE / REG）、PLAY（DRIFT の RATE / RANGE / REACH。画面の見出しに ON / OFF）。KNOB 1〜4（各トラックの音量）は動詞を押している間も変わらない（SEQ と ARP の間だけは何もしない）。SAVE と REC は機能を持たない（弾いた音は常にフレーズへ溶け込む）。

パラメータは押している間だけ上乗せされ、離すと元の値（その間にマクロが書いた値があればそれ）に戻る。上段の動詞の量は、押すと約0.3秒で立ち上がり、離すと約0.6秒で消える（SINK だけは自前の速さ）。FREEZE・TAPE・SWEEP・REPEAT・ハーモナイザー・RISE・KEEP・TWIST・FOG の旧動詞は外した（perform.c の中身は残る）。設計の経緯は docs/VERBS_PLAN.md。

## 画面：操作子の物理配置と揃えた4分割

240×240 の画面を 120×120 の4つの区画に分ける。各区画は、画面の左にある 2×2 のつまみの位置に対応させる。

```
 本体のつまみ              画面
┌────────┬────────┐   ┌──────────┬──────────┐
│ MASTER │ SELECT │   │ 波形      │ SELECT の │
│        │        │   │ BPM・音量 │ パラメータ │
├────────┼────────┤   ├──────────┼──────────┤
│PRESETS │ALGORITHM│  │ PRESETS の│ALGORITHM の│
│        │        │   │ パラメータ │ パラメータ │
└────────┴────────┘   └──────────┴──────────┘
```

- **左上（MASTER の位置）**：波形を表示する。あわせて、どのモードでも次の3つを常に表示する。
  - BPM の数字
  - 4トラックの音量を示す細いバー（KNOB 1〜4 の並びの順）
  - フォーカス中のトラック
- **右上・左下・右下**：それぞれ SELECT・PRESETS・ALGORITHM が今動かしているパラメータの名前と値。
- **すべてのモードを同じ様式で表示する。** ボタンを押している間に、3つのつまみの役割が変わるモード（GLO のテンポなど）も同じ。役割が変わったつまみの区画だけ表示が入れ替わる。
- 1つのモードに割り当てるパラメータは**最大3つ**。区画に収まらないページ送りは作らない。

## 決まったこと（実装済み）

各トラックの3つのパラメータ（1つのつまみが、最大3つの実パラメータを同時に動かす）。右に回すほど盛り上がる。

| トラック | SELECT | PRESETS（音色） | ALGORITHM |
|---|---|---|---|
| 1 脈 | DENS（密度） | TONE：TONE↑、SNAP↑、DECY↓ | WASH：リバーブ送り、ディレイ送り、DRV |
| 2 床 | OPEN：和音の声数（2〜4）。中央（64）より下は間延び：次の和音を打たず前の和音を鳴らし続ける（最大70%） | TONE：BRIT、BUZZ | SWAY：コーラス、フィルターLFO、リリース |
| 3 霞 | GRAIN：DENS↑、SIZE↓。中央より下は間延び：音を間引く／前の音を伸ばす（最大70%） | TONE：TONE、SPRD、RAND | AIR：リバーブ、ディレイ、アタック |
| 4 声 | LOOSE：ほどけ（再抽選）と昇り（1オクターブ上）。中央より下は間延び：音を間引く（最大65%） | TONE：BRIT、DAMP↓、ACC | TRAIL：ディレイ、リバーブ、リリース |

- 起動時と HOME 長押しで、床・霞・声の音色（プリセット）と、全マクロの値がランダムに決まる。
- SEQ を押している間、密度に最大 +80 が約5秒かけて足される（ライザー）。離すと約0.25秒で落ちる。
- 鍵盤で弾いた音は、REC を押さなくても常に声のフレーズへ溶け込む（キックにフォーカスしているときの鍵盤はステップなので除く）。最新の8音を覚え、フレーズのステップごとに35%で、覚えている音から1つが鳴る。音は鳴るたび・試すたびに薄れ、弱い音ほど鳴らなくなる。9音目からは、いちばん古い（いちばん薄い）音が押し出される。スケール外の音は、さらに拾われにくい。
- ARP（根音・スケール）と SEQ（テンポ）だけは、従来のレイヤー（旧 SCL と GLO の中身）のまま。
- HOME を押しながら OCT− を押すと、設定メニュー（色、画面オフ、キャリブレーション）が開く。メニューを閉じるのは HOME。
- CC20 は、キックの SELECT（密度）。

## 音色の幅：出し方と声のカタログ（実装済み）

音は「エンジン＋プリセット」だけでなく、**出し方（ART）**と組で世界ごとに決まる（`maku_voices.c`、設計と測定は docs/VOICES_RATING.md）。

| 出し方 | 立ち上がり | 持続 |
|---|---|---|
| STRK 打つ | 即 | 短い（今までの音） |
| SOFT 柔らかく打つ | 約0.15秒 | 短い |
| SWEL ふくらむ | 約2秒 | 次の音まで保つ（TIE） |
| BOW 擦る | 約0.5秒、励起が続く | 次の音まで |
| HOLD 置く | 約1.4秒 | 和音が変わるまで |

- 床は9通り、霞は5通り、声は10通り。床の約8割と霞の約8割が持続系で、**床と霞の少なくとも一方は必ず持続**。
- 持続系の床と霞は DIV 1/8（和音は約7秒ごと）。声の SWEL / BOW は「ゆっくりした旋律」：4ステップに1音、次の音まで保つ。
- ボイスはパートごとに上限（床3、持続の霞2、声2、キック1）。ATK / REL のマクロは持続系では土台の前後だけ動く。

## 空間系の味付け（実装済み）

このファームウェアに入れた時点で、MAKU 以外のモードはない。そこで、3つのバスに個性を持たせた（`firmware/src/fx.c`）。ウェット側はステレオで返る。

- **コーラス**：2タップのアンサンブル。左右が別の LFO（右はやや遅く、3分の1周ずれる）で揺れる。声が散って、像が開く。
- **ディレイ**：テープ。読み出し位置がゆらぎ（ワウ・フラッター）、フィードバックは低域が削られ、ソフトクリップで少しつぶれる。繰り返すたびに、暗く、薄く、荒くなる。右は同じ線の 3/4 の位置を聴く（別のリズムになる。バッファは増やしていない）。
- **リバーブ**：ROOM に 25 ms のプリディレイ。4つのコムのうち2つの読み出し位置が、ゆっくり動く（尾が一点で鳴り続けず、うっすら揺れる）。コムを左右に別々の割合で混ぜて、広がりを出す。SPRING は従来どおり（モノを両側へ）。
- **逆再生リバーブ**：リバーブの戻りを1拍ずつ録り、逆向きに再生する。2乗で立ち上がって、拍の頭に向かってふくらみ、拍で切れる。2つのバッファを交互に使い、半分のレートで録る（0.74秒まで）。量は、霞の AIR で決まる（約20より上で入ってくる）。

## 処理負荷の見積もり（実機では未測定）

ホスト（Linux）上で、全体のミックスの ns/サンプルを測り、docs/MAKU.md の旧 MAKU（密度127、約 1739 命令/サンプル、実機でおよそ30%）との比で換算した。

| 状態 | 旧 MAKU 比 | 実機の見積もり |
|---|---|---|
| 旧 MAKU（密度127） | ×1.0 | 約 30% |
| 今の世界の最悪（密度127、OPEN・LOOSE 127） | ×1.7 | 約 51% |
| 同じ最悪に FREEZE・ハーモナイザー・REPEAT・LPF を全部押さえる | ×2.1 | 約 63% |

- 空間系の味付けで、全体に約 +4.5% 足された（静かなときも、バスは常に動く）。
- オーバーロード時の保護（2ブロック続けて 85% を超えると、ボイスを1つずつ減らす）は残っている。最悪のときでも、そこまでは約20%の余地がある。
- 換算は ns の比によるもので、実機の命令数やキャッシュの違いは入っていない。実機で確かめるまでは、目安として扱う。

## INSERT（試用中）

Felucca 1.5 の INSERT（トラックごとの歪み・フェイザー等）を、ドローンとシマーにだけ使っている。使えなければ削除する（手順は docs/decisions.md）。

- 世界ごとに決まる：ドローンは PHASR / CHOR / なし、シマーは FLANG / CHOR / なし。速さ（RATE）は 0.1〜0.5 Hz、深さと戻し（DEPTH / FDBK）は世界ごとにランダム。キックとアルペジオには付けない。
- 動かすのは各 TONE マクロ（ドローン：MIX 20〜110、シマー：GRAIN マクロの MIX 0〜90）。なしの世界では何も起きず、負荷もかからない。
- 実機用ビルドの実測：フラッシュ +2.0 KB、RAM +0.1 KB、プール +2.3 KB。オーディオ割り込みの静的な負荷は変わらない。ホストでは、両方に PHASR を最大にかけて旧 MAKU 密度127 の +15〜20%（実機では約 +5 ポイントの見積もり、未測定）。

## 未決（実装しながら決める）

- 起動時ランダムの範囲。どこまで振れても「いい感じ」に収まるか。耳で調整が必要。
- 4つの音量を同時に上げたとき、音同士が避け合う動き（ダッキングの拡張）。
- ゴースト（密度が足すキック）を LED で暗く表示すること。
