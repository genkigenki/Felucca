# 呼吸の域（計画・未実装）

2026-10-12。MAKU のテンポの下端を「呼吸」に読み替える計画。別モードでも別ファームでもない。現行の仕様は AMBIENT.md。
この文書は、決めたことと理由、作る順番。

## 0. 位置づけ

MAKU は「間」のための機械。速い端では DJ の幕間を埋め、遅い端では呼吸の間になる。設定はなく、テンポを左へ下ろしていく
だけで、幕間は坐禅に、坐禅は眠りに続いていく。

- **モードと呼ばない**。モードは意味を切り替えるもの。ここでは同じ部品が、値の遅い端で別の意味を帯びる（「域」）。
- 先例：Buddha Machine（FM3、2005）と、その元の念仏機。小さなスピーカーで、つなげば鳴っている箱。
- 流儀から：マインドフルネスと禅は呼吸を**操作しない**（観る・随う）。呼吸のペースを命じるのは調気法（pranayama）や
  共鳴呼吸の側。なので既定は「錨」：ゆっくりした周期を置いておくだけで、合わせても合わせなくてもよい。
- 禅（坐る）と眠りは逆向き（坐禅では眠気＝昏沈は障り）。出口を2つに分ける：**坐る**（鐘で始まり鐘で終わる）と
  **眠る**（鐘なし、暗く閉じて消える）。

### MAKU の原則との突き合わせ

| 原則 | 禅との関係 | 扱い |
|---|---|---|
| 起動したらもう鳴っている | 一致（準備しない） | そのまま |
| 保存しない・毎回新しい世界 | 一致（無常） | そのまま。毎晩同じ音が欲しければ、いいね（BPM も残る） |
| 外れない | 一致 | そのまま |
| 右へ回すほど賑やか | 緊張 | 言い直す：「右＝動、左＝静。どちらも良い」。呼吸の域は左の端 |
| ボタン1つが動詞1つ | 緊張（禅は何もしない） | 呼吸の域では動詞を浅く。足す動詞は「やめる動詞」（坐る・眠る）だけ |
| いいねで好みが育つ | 少し緊張（執着） | 「少し変えて」選び直すのが執着をゆるめる。そのまま |
| 会場で他人のため | 向きが逆（自分のため） | 同じ機械を逆向きに使う、と割り切る |

### 入れないもの

セッションの選択画面・メニュー、点数・連続記録、声の誘導、既定でペースを命じること、効能の表示（「眠れる」は体験の言葉に
留め、医療的な主張はしない）。

## 1. 域の取り方（決定：起動の下限 70 から段階的にモーフ）

**起動の範囲（70〜90 BPM、ui.c）の下限 70 から下を、呼吸へ少しずつ変わっていく坂にする。70 以上は今まで通りのテンポ。**
境の一点で切り替えるのではなく、70 → 50 の 20 目盛りをかけてテンポが呼吸に溶け、50〜40 は呼吸の中で遅さだけが変わる。
BPM の範囲（params.c `G_BPM` 40..240）は変えない。

理由：起動の世界は 70〜90 で、会場でつなぐときテンポは上げる方向にしか触らない。70 より下は今は使われていない場所なので、
そこを丸ごと坂に使えば、目盛りが細かく、変化もゆるやかになる（40〜49 の 10 目盛りだけより、ずっとなだらか）。

- 起動のランダムと HOME の振り直しは 70 以上なので、会場の使い方は変わらない。
- 変わるのは「今 40〜69 BPM で使っていた人」。50〜69 では、キックが少し引き、膨らみが少し入る。受け入れる。
- **MIDI クロック追従中（`G_CLOCK`）は坂に入らない**（外の時計が勝つ。遅いクロックでも呼吸にはならない）。
- タップテンポで 70 より下に落ちたら坂に入る（それで良い）。
- DRIFT の REACH 86+ はテンポもさまよわせる：**70 より下へは行かせない**（頼まれずに呼吸へ連れていかない）。
  70〜72 から始まった世界でも、坂には入らない。
- いいねは BPM を持ち、変異で BPM は変えない（maku_fav.c）。呼吸の世界をいいねすれば、呼吸の世界が戻る。

### 1呼吸の長さ：テンポの続き

**1小節 = 1呼吸は、どのテンポでも同じ。** 70 BPM の1小節は 3.4 秒（毎分約 17 回、安静時の呼吸の範囲）。
70 より下では、BPM の値を「実効テンポ」に曲げていく。曲げ始めは傾きまで 70 で続いている（段差も折れもない）：

`x = (70 − 値) / 30`、`e = 値 × (13.33 / 40)^(x²)`

| BPM 値 | 70 | 69 | 65 | 60 | 55 | 50 | 45 | 40 |
|---|---|---|---|---|---|---|---|---|
| 実効テンポ | 70 | 68.9 | 63.0 | 53.1 | 41.8 | 30.7 | 21.0 | 13.3 |
| 1呼吸（秒） | 3.4 | 3.5 | 3.8 | 4.5 | 5.7 | 7.8 | 11.4 | 18 |
| 重み `w` | 0 | 0.01 | 0.16 | 0.5 | 0.84 | 1 | 1 | 1 |

左へ回すほど遅い（静か）。45〜47 あたり（約 10 秒、毎分6回）が共鳴呼吸の目安。内部のステップ時計は 16 ステップで
1呼吸で、フレーズは吸う頭（ステップ 0）に揃う。

### 坂の重み：状態を跳ばさない

域は「入る・出る」のスイッチではなく、**重み `w`（0..1）** で持つ。

- `w` は値で決まる：`y = (70 − 値) / 20` を 0..1 に収め、`w = y²(3 − 2y)`（両端がなめらかな S 字）。70 以上で 0、
  60 で 0.5、50 以下で 1（耳で詰める）。名前と同じく、別の状態を持たない。
- `w` は時間でもなめらかにする（スルー、約1呼吸）。つまみを素早く回しても、MIDI クロックが止まって値が効き始めても、
  音は飛ばない。MIDI クロック追従中は `w` の目標が 0。
- **位相は引き継ぐ**：坂に入っても小節を頭に戻さない。呼吸の位相は今のステップ位置（16 分のいくつ）そのもの。
- 実効テンポ自体が続いている（上の表）ので、ステップの間隔も、拍で数える動詞の時間も跳ばない。

`w` で混ぜるもの：

| もの | `w` = 0（テンポ） | `w` = 1（呼吸） |
|---|---|---|
| 呼吸の包絡 `b(t)` の深さ | 0 | DEPTH の分 |
| キックの音量とダッキング | 今まで通り | 0（`1 − w` で絞る。ステップは止めない） |
| アルペジオの SWING | SWING の値 | 0（`1 − w`） |
| 吐く割合（EXHALE） | 50 %（効かない） | EXHALE の値（`w` で寄せる） |
| 動詞の効く量 `MAKU_PEAK` | 1 倍 | 0.5 倍（`1 − 0.5 w`） |
| 左上の錨の輪 | 出ない | 輪の膨らみの振れ幅が `w` に比例（波形から輪が育つ） |

**跳んでよいもの（合図として）**：つまみの名前（BPM → BREATH ほか）と、値の表示（数字 → 秒）。これは「呼吸の側に
入った」ことを知らせる表示で、音ではない。名前は坂の真ん中、`w` が 0.5 を越えたところ（値が 60 以下）で切り替わる。

SIT / SLEEP は一度始まったら、値が 50 以上に戻っても続く（止めるのは SAVE）。新しく始められるのは名前が BREATH の間（値が 60 以下）だけ。

## 2. 名前と画面

名前は「いまの意味」を書く（ui_maku.c はすでに文脈で名前を選んでいる：テンポ層の BPM、動詞の RISE / HOLD / FADE）。
値の位置だけで決まり、別の状態を持たない。境で表示が跳ぶこと自体が「域に入った」合図。

| 今 | 呼吸の域 | 意味 |
|---|---|---|
| BPM | BREATH | 1呼吸の秒数。値の表示は秒（L フォントに `S` が無ければ足す。UI_RULES：足すだけ） |
| SWING | EXHALE | 吐く割合。0 → 50 %、64 → 60 %（4:6）、127 → 70 % |
| DUCK | DEPTH | ドローンが息をする深さ。0 = なし、64 = 錨（浅い）、127 = はっきりしたガイド |
| 左上の波形 | 呼吸の錨 | 呼吸の位相で膨らみ縮む輪。左上の BPM の数字も秒に |

変えないもの：役の名前（脈・床・霞・声）とトラック色、区画の配置と色の役割、**印字のある動詞の名前**
（SAVE は見出し SAVE のまま、名前を SIT / SLEEP に）。名前は大文字7文字まで。

## 3. 音

- **呼吸の包絡** `b(t)`（0..1）：吸う間に S 字で上がり、吐く間に S 字で下がる。止めは v1 では置かない。
  床と霞の音量とフィルタ（TONE）を DEPTH の分だけ動かす。
- **DUCK はそのままは使えない**：今のダッキング（maku.c `maku.duck`）はキックが鳴ったときだけ沈み、約 120 ms で戻る
  固定の時定数で、テンポに付いてこない。呼吸の域では、DUCK の値を `b(t)` の深さとして読み、キックのダッキングは `1 − w` で絞る。
- **脈（キック）**：`w` が 1 に近づくにつれて絞り、46 以下では聞こえない（v1）。吸う合図は既定でなし（錨）。
- **動詞**：拍で数えるので、遅い時計では自然に長くなる（1拍 1.4〜4.5 秒、FADE 32 拍で最長約 144 秒）。効く量
  （`MAKU_PEAK`）は `w` に応じて半分まで下げる（耳で詰める）。
- **ディレイ**：拍同期（fx.c）だと拍が最長 4.5 秒になる。バッファの長さでクランプし、テンポが動くときの時間の変化はなめらかにする（要確認）。
- スピーカー向け：小さなスピーカーと小さな音量では低音が出ない。床は倍音で聞かせる（耳で詰める）。

## 4. 坐る・眠る（SAVE）

SAVE は今なにもしない。名前が BREATH の間（値が 60 以下）だけ動詞になる（それ以外は今まで通りなにもしない）。

| 操作 | 名前 | 中身 |
|---|---|---|
| タップ | SIT | 鐘を一つ（声の PHYS で根音を高めに、打つ）。線香一本＝20 分（v1 は固定）のあと、鐘を一つ |
| 長押し（約 1 秒） | SLEEP | 30 分かけて全体が暗く閉じ、消える。消えたあとは無音のまま、何か触れば戻る |
| 動いている間にもう一度 | — | 取り消し |

LED：SAVE は動いている間「呼吸」（UI_RULES：呼吸 = 開いている間）。眠る間、ほかの LED は消す。
画面：眠るときは MENU > SCREEN OFF を使う。**バックライトは消せない**（lcd.c：PA2 はキーマトリクスと共用。消すと何も
読めず起こせない）ので、暗い部屋での漏れを実機で確かめる。

## 5. 作る順番

1. 実効テンポの曲線（値 → `e`）と重み `w`（値で決まり、時間でスルー、G_CLOCK 中は 0）。位相は引き継ぐ。DRIFT は 70 より下へ行かない。
2. 呼吸の包絡 `b(t)` と DEPTH / EXHALE、`w` による混ぜ（キック・ダッキング・SWING・`MAKU_PEAK`）。
3. 名前（BREATH / EXHALE / DEPTH）と秒の表示、L フォントの `S`。署名に域を足す（UI_RULES 6）。
4. 左上の錨（毎フレーム描く「動くもの」として）。
5. SAVE の SIT / SLEEP と LED。
6. テスト：70 → 40 → 70 を回して音量・テンポ・包絡に段差がない（ブロックごとの差が上限以下）、域の出入りで名前が変わる、G_CLOCK 中は域に入らない、DRIFT が境をまたがない、SLEEP の終わりで無音、
   左上のスクリーンショット（PPM）。

## 6. 未決・確かめること

- 実効テンポの曲線と `w` の幅、EXHALE と DEPTH の幅、動詞の半分、線香と眠りの長さ（耳で）。
- 吸う頭の合図（鈴）を DEPTH の高い側で足すか。
- 実効テンポ 13〜70 BPM で、シーケンサーと拍同期の効果がどこで破綻するか。
- 暗い部屋での画面の漏れ、内蔵スピーカーでの床の聞こえ方（実機）。
- 電池（UI_RULES 10）：一晩の SLEEP で電池がどれだけ減るか。眠る間は BATTERY LOW のメッセージで画面を起こさない
  （`MANNER:battery` の例外として足すか）。SLEEP の終わりの無音は `MANNER:fade-in` と同じく、ぶつ切りにしない。
