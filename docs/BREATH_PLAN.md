# 呼吸の域（計画・未実装）

2026-10-12。MAKU のテンポの下端を「呼吸」に読み替える計画。別モードでも別ファームでもない。現行の仕様は AMBIENT.md。
この文書は、決めたことと理由、作る順番。

## 0. 位置づけ

MAKU は「間」のための機械。速い端では DJ の幕間を埋め、遅い端では呼吸の間になる。設定はなく、テンポを左へ下ろしていく
だけで、幕間は坐禅に、坐禅は眠りに続いていく。

- **モードと呼ばない**。モードは意味を切り替えるもの。ここでは同じ部品が、値の遅い端で別の意味を帯びる（「域」）。
- 先例：Buddha Machine（FM3、2005）と、その元の念仏機。小さなスピーカーで、つなげば鳴っている箱。
- 流儀から：マインドフルネスと禅は呼吸を**操作しない**（観る・随う）。呼吸のペースを命じるのは調気法（pranayama）や
  共鳴呼吸の側。なので既定は「錨」：ゆっくりした周期を置いておくだけで、合わせても合わせなくてもよい。
- 禅（坐る）と眠りは逆向き（坐禅では眠気＝昏沈は障り）。出口を2つに分ける：**坐る**（鐘で始まり鐘で終わる）と
  **眠る**（鐘なし、暗く閉じて消える）。

### MAKU の原則との突き合わせ

| 原則 | 禅との関係 | 扱い |
|---|---|---|
| 起動したらもう鳴っている | 一致（準備しない） | そのまま |
| 保存しない・毎回新しい世界 | 一致（無常） | そのまま。毎晩同じ音が欲しければ、いいね（BPM も残る） |
| 外れない | 一致 | そのまま |
| 右へ回すほど賑やか | 緊張 | 言い直す：「右＝動、左＝静。どちらも良い」。呼吸の域は左の端 |
| ボタン1つが動詞1つ | 緊張（禅は何もしない） | 呼吸の域では動詞を浅く。足す動詞は「やめる動詞」（坐る・眠る）だけ |
| いいねで好みが育つ | 少し緊張（執着） | 「少し変えて」選び直すのが執着をゆるめる。そのまま |
| 会場で他人のため | 向きが逆（自分のため） | 同じ機械を逆向きに使う、と割り切る |

### 入れないもの

セッションの選択画面・メニュー、点数・連続記録、声の誘導、既定でペースを命じること、効能の表示（「眠れる」は体験の言葉に
留め、医療的な主張はしない）。

## 1. 域の取り方（決定：B）

**SEQ の BPM 40〜49 を呼吸の域にする。50 以上は今まで通りのテンポ。** BPM の範囲（params.c `G_BPM` 40..240）は変えない。

- 起動のランダム（70〜90、ui.c）と HOME の振り直しは域の外なので、会場の使い方は変わらない。
- 変わるのは「今 40〜49 BPM で使っていた人」だけ。受け入れる。
- **MIDI クロック追従中（`G_CLOCK`）は域に入らない**（外の時計が勝つ。midi_clock.c は 40..240 にクランプするので、
  遅いクロックでも呼吸にはならない）。
- タップテンポで 40〜49 に落ちたら域に入る（それで良い）。
- DRIFT の REACH 86+ はテンポもさまよわせる：**50 の境をまたがせない**（アンカーの側にクランプ）。
- いいねは BPM を持ち、変異で BPM は変えない（maku_fav.c）。呼吸の世界をいいねすれば、呼吸の世界が戻る。

### 1呼吸の長さ

域の中の値 → 1呼吸の秒数（耳で詰める初期値）：

| BPM 値 | 49 | 48 | 47 | 46 | 45 | 44 | 43 | 42 | 41 | 40 |
|---|---|---|---|---|---|---|---|---|---|---|
| 1呼吸（秒） | 8 | 9 | 10 | 11 | 12 | 13 | 14 | 15 | 16 | 18 |

左へ回すほど遅い（静か）。10 秒（毎分6回）が共鳴呼吸の目安。

**1小節 = 1呼吸。** 内部のステップ時計は 16 ステップで1呼吸（実効テンポ 240 / 秒数 BPM、8 秒で 30、18 秒で約 13）。
フレーズや鐘が吸う頭に揃う。

## 2. 名前と画面

名前は「いまの意味」を書く（ui_maku.c はすでに文脈で名前を選んでいる：テンポ層の BPM、動詞の RISE / HOLD / FADE）。
値の位置だけで決まり、別の状態を持たない。境で表示が跳ぶこと自体が「域に入った」合図。

| 今 | 呼吸の域 | 意味 |
|---|---|---|
| BPM | BREATH | 1呼吸の秒数。値の表示は秒（L フォントに `S` が無ければ足す。UI_RULES：足すだけ） |
| SWING | EXHALE | 吐く割合。0 → 50 %、64 → 60 %（4:6）、127 → 70 % |
| DUCK | DEPTH | ドローンが息をする深さ。0 = なし、64 = 錨（浅い）、127 = はっきりしたガイド |
| 左上の波形 | 呼吸の錨 | 呼吸の位相で膨らみ縮む輪。左上の BPM の数字も秒に |

変えないもの：役の名前（脈・床・霞・声）とトラック色、区画の配置と色の役割、**印字のある動詞の名前**
（SAVE は見出し SAVE のまま、名前を SIT / SLEEP に）。名前は大文字7文字まで。

## 3. 音

- **呼吸の包絡** `b(t)`（0..1）：吸う間に S 字で上がり、吐く間に S 字で下がる。止めは v1 では置かない。
  床と霞の音量とフィルタ（TONE）を DEPTH の分だけ動かす。
- **DUCK はそのままは使えない**：今のダッキング（maku.c `maku.duck`）はキックが鳴ったときだけ沈み、約 120 ms で戻る
  固定の時定数で、テンポに付いてこない。呼吸の域では、DUCK の値を `b(t)` の深さとして読むだけで、キックのダッキングは止める。
- **脈（キック）**：呼吸の域では鳴らさない（v1）。吸う合図は既定でなし（錨）。
- **動詞**：拍で数えるので、遅い時計では自然に長くなる（1拍 2〜4.5 秒、FADE 32 拍で最長約 144 秒）。効く量
  （`MAKU_PEAK`）は域の中で半分にする（耳で詰める）。
- **ディレイ**：拍同期（fx.c）だと拍が 2 秒を超える。バッファの長さでクランプする（要確認）。
- スピーカー向け：小さなスピーカーと小さな音量では低音が出ない。床は倍音で聞かせる（耳で詰める）。

## 4. 坐る・眠る（SAVE）

SAVE は今なにもしない。呼吸の域でだけ動詞になる（域の外では今まで通りなにもしない）。

| 操作 | 名前 | 中身 |
|---|---|---|
| タップ | SIT | 鐘を一つ（声の PHYS で根音を高めに、打つ）。線香一本＝20 分（v1 は固定）のあと、鐘を一つ |
| 長押し（約 1 秒） | SLEEP | 30 分かけて全体が暗く閉じ、消える。消えたあとは無音のまま、何か触れば戻る |
| 動いている間にもう一度 | — | 取り消し |

LED：SAVE は動いている間「呼吸」（UI_RULES：呼吸 = 開いている間）。眠る間、ほかの LED は消す。
画面：眠るときは MENU > SCREEN OFF を使う。**バックライトは消せない**（lcd.c：PA2 はキーマトリクスと共用。消すと何も
読めず起こせない）ので、暗い部屋での漏れを実機で確かめる。

## 5. 作る順番

1. 域の判定（`!G_CLOCK && BPM < 50`）と 1呼吸の秒数の表、ステップ時計を1呼吸 = 16 ステップに。DRIFT の境クランプ。
2. 呼吸の包絡 `b(t)` と DEPTH / EXHALE、域でのダッキング停止と脈の休み。
3. 名前（BREATH / EXHALE / DEPTH）と秒の表示、L フォントの `S`。署名に域を足す（UI_RULES 6）。
4. 左上の錨（毎フレーム描く「動くもの」として）。
5. SAVE の SIT / SLEEP と LED。
6. テスト：域の出入りで名前が変わる、G_CLOCK 中は域に入らない、DRIFT が境をまたがない、SLEEP の終わりで無音、
   左上のスクリーンショット（PPM）。

## 6. 未決・確かめること

- 1呼吸の秒数の表、EXHALE と DEPTH の幅、動詞の半分、線香と眠りの長さ（耳で）。
- 吸う頭の合図（鈴）を DEPTH の高い側で足すか。
- 実効テンポ 13〜30 BPM で、シーケンサーと拍同期の効果がどこで破綻するか。
- 暗い部屋での画面の漏れ、内蔵スピーカーでの床の聞こえ方（実機）。
