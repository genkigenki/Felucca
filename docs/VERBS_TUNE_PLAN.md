# 動詞の手触りの見直し（設計・未実装）

2026-10-11。上段の6つの動詞（SINK CASCADE SWELL WOBBLE LIFT SCRAMBLE）について、2つの変更の設計。

1. **押し方**：押しっぱなしをやめ、「一度押すと数秒効いて、ゆっくり元へ戻る」にする。
2. **効き方**：SWELL・LIFT・SCRAMBLE が何をしているのか耳で分からない。意図した効果がはっきり出るように強める。

1 は 2 の前提でもある。今の SWELL は「次に鳴る音」にしか効かず、床の和音が替わるのは数秒〜十数秒に一度なので、短く押しただけでは
何も起きないことが多い。効いている時間が数秒あれば、次の和音まで届く。

---

## 1. 押し方：数秒効いて、ゆっくり戻る

### 振る舞い

各動詞の量（`maku.va`、0..1）が4つの段を通る。

```
 量
 1 ┤    ┌──────────────┐
   │   ╱ 押している間 + 保持 ╲
   │  ╱                      ╲___
 0 ┼─┘                           ╲________
   押す  離す   ←保持→    ←戻り（ゆっくり）→
   上がり
```

| 段 | 長さ | 中身 |
|---|---|---|
| 上がり | 約0.3秒（今のまま） | 押した瞬間から 0 → 1 |
| 押している間 | 押している限り | 1 のまま（今の押しっぱなしの使い方もそのまま使える） |
| 保持 | 離してから **HOLD**（既定 2小節） | 1 のまま |
| 戻り | **FADE**（既定 2小節） | 1 → 0。直線でなく、初めゆっくり終わりもゆっくり（S字）。最後の方は聞こえないほど小さく変わるので、「いつの間にか戻っていた」になる |

- **保持は離した時から数える**。タップなら押した時とほぼ同じ。長く押せば、押していた分だけ伸びる。
- **長さは小節で数える**（テンポに付いてくる）。72 BPM で 2小節＝約6.7秒。秒で固定すると、遅い世界では短く、速い世界では長く感じるため。
- **保持中・戻り中にもう一度押す**：今の量から上がり直し、保持をやり直す（延長）。止める操作は設けない（止めたければ待つ。SINK と同じく、
  戻りが性格の一部）。→ 決めること 2
- **複数の動詞**はそれぞれ別に数える（重ねがけ可）。
- **画面とつまみ**：押している間だけその動詞の3つのパラメータ（今のまま）。離したら画面とつまみはマクロに戻る。効いている途中で
  マクロを弾ける方が、「数秒効く」の使い道が広がるため。
- **SINK**：今の自前の速さ（約0.5秒で潜り、約3秒で浮かぶ）を残し、間に保持だけを足す。浮かぶ速さは FADE に合わせず、今の約3秒のまま
  （→ 決めること 1 で一緒に決める）。
- **PLAY（DRIFT）**：対象外。今のトグルのまま。

### LED（効いている印）

押しっぱなしでなくなると、何が効いているかが手から分からなくなる。上段の LED で示す（今の MAKU では上段は点けていない）。

| 段 | LED |
|---|---|
| 上がり・押している間・保持 | 点灯 |
| 戻り | 息をする（`fm1_led_breath`、暗〜約60 %） |
| 0 | 消灯 |

FX の LED は MAKU 以外では FX LATCH の印だが、MAKU のときは使っていないので食い違わない。

### 今のコードでの要点（実装の手引き）

- `maku.va` は今「押している（`hv` のビット）なら上げ、離したら下げる」。これに動詞ごとの**残り時間**（ブロック数、`uint16_t`）を足す。
  押している間は満タンに張り直し、離した後は数えて減らし、0 になったら戻りに入る。小節の長さはテンポ（`song.g[G_BPM]`）から毎回求める。
- 戻りは約7秒を 1ブロック約1.2 ms で刻むので、Q12 の `va` では1ブロックの減り幅が1未満になる。内部は Q16（`int32_t`）で持ち、
  外へは今の Q12 を出す。S字は「内部の時間 → 量」の表で引く。
- **`hv` のビットで効き目を決めている所を、すべて `va` に替える**。今は CASCADE の発音（`maku_arp_step` の `casc`）、SCRAMBLE の跳躍と
  キックのゴースト、SWELL の STAY（`maku_stay`）が「押しているか」の 0/1 で効く。このままでは「離した瞬間に切れる」か「戻りの間ずっと
  全開」になる。確率に `va` を掛け、戻りに沿って薄れるようにする。
- SINK：`maku.brk`（押している）を「押している、または保持中」に。
- `hv` は「今押しているボタン」の意味だけに戻す（画面とつまみの割り当て、PLAY のタップ判定）。

## 2. 効き方：SWELL・LIFT・SCRAMBLE を派手に

共通の方針：**押して1拍以内に何か聞こえる**こと。今の3つはどれも「次に起きること」を少し変えるだけで、しかも変化量が上限の3割前後に
留まっている。

### SWELL（膨らむ。軸：時間が長く伸びる）

**今弱い理由**
- アタックとリリースは「これから鳴る音」にしか効かない。床は約19ステップに一度しか打たれず、持続する声部は打ち直さないので、
  押している間に新しい音が来ないことが多い。
- 足し分は ATTACK 60 の場合で +60（パラメータの約半分）。もともとアタックが長い声では差が出ない。
- 声のアルペジオは粒のまま。いちばん頻繁に鳴る声部が変わらないので、「伸びた」と感じない。

**変更**
| 項目 | 内容 |
|---|---|
| 打ち直し | 効き始めた瞬間に、床と霞が**今の和音を長いアタックで打ち直す**（`dc[]` を流用。持続する声部も一度だけ打ち直す）。押すとすぐ和音がゆっくり膨らみ直すのが聞こえる。これが SWELL の名刺 |
| ATTACK・RELEASE | 「今の値＋足し分」から「**上へ寄せる**」（`maku_up` と同じ形：ATTACK 127 でアタックが上限まで）に変える。短いアタックの声ほど大きく変わる |
| 声 | **STAY をアルペジオにも効かせる**：STAY の分だけ、声が遅い旋律（`MAKU_SLOW`：4ステップに1音、伸ばす）になる。粒が線になる |
| 音量 | 床と霞を少し持ち上げ（最大 +3 dB 程度）、キックと声を少し下げる（`maku_gain`）。量に沿うので、効き始めに膨らみ、戻りでしぼむ |

パラメータの名前は ATTACK / RELEASE / STAY のまま。STAY の説明に「声が伸びる」を足す。

### LIFT（持ち上げる。軸：音色が前へ、明るく、硬く）

**今弱い理由**
- TONE の足し分は既定 40（マクロ全体の3割）、EDGE は歪みに最大 +24、THIN はハイパスの約3割。3つとも控えめで、
  しかも同時に一気に来るので「少し変わった」で終わる。

**変更**
| 項目 | 内容 |
|---|---|
| 振れ幅 | TONE は「足し分」から「上へ寄せる」に（TONE 127 で全トラックの TONE マクロが 127 まで）。EDGE は歪みに最大 +80。THIN はハイパスの全域（100）まで |
| 上がり方 | LIFT だけ**上がりを遅くする**（約0.3秒ではなく、保持の間ずっと少しずつ上がり続ける）。押すと音がせり上がっていく、ライザーの動き。保持が終わる時に頂点、戻りで降りる |
| 音域 | **声と霞が1オクターブ上がる**（量が半分を超えたところから、確率で。TONE で強さ）。「持ち上げる」が音色だけでなく耳にはっきり出る → 決めること 3 |

### SCRAMBLE（崩す。軸：拍とフレーズの秩序が崩れる）

**今弱い理由**
- アルペジオの「跳躍」は表の別の場所へ移るだけ。もともと表の場所はランダムに選ばれているので、跳んでも同じ調・同じ音域・
  同じ間合いで、崩れたように聞こえない。
- キックのゴーストは既定で最大 +19 %、揺れ（SWING）は最大 +15。

**変更**
| 項目 | 内容 |
|---|---|
| ARP | 跳躍に加えて、**連打（ラチェット 2〜4、`step_set_ratchet`）**、**オクターブの飛び（±12）**、**休符の挿入**を ARP の確率で。調の外には出ない（`maku_note` のまま） |
| KICK | ゴーストを最大 +60 % に。ゴーストに連打（ロール）を混ぜる。手で置いた拍もときどき**抜ける**（表拍が消えると、拍の秩序が崩れたのがすぐ分かる） |
| SWING | 最大 +40 → 声の SWING の上限（100）まで |
| 霞 | 霞の2つの打点（ステップ 0 と 7）が、ときどき前後にずれる（KICK の量で） |

### 3つ以外（SINK・CASCADE・WOBBLE）

今回は手を入れない。押し方の変更（1）で `hv` を `va` に替える分だけ触る。

## 決めること

1. **HOLD と FADE の長さ**：既定 2小節＋2小節を提案。固定にするか、世界ごとの設定（HOME の設定画面）に出すか。SINK の浮かぶ速さも
   FADE に揃えるか。
2. **保持中にもう一度押したとき**：延長（提案）か、止める（トグル的）か。
3. **LIFT のオクターブ上げ**：入れる（提案）か。音域は CASCADE の SPAN と役が近いので、外して音色だけに留める手もある。
4. **SWELL の音量の持ち上げ**：+3 dB でクリップしないかはマスターの余裕次第。実機で聞いて、駄目なら「キックと声を下げる」だけにする。
